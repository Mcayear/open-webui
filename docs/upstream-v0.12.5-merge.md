## 冲突与仓库定制

唯一内容冲突是 `backend/open_webui/utils/subagents.py`。以目标上游文件为主体解决，只保留未覆盖的当前请求附件来源。图片保存在子聊天 `files` 及用户消息 `files`；内部完成请求顶层 `files` 按上游规则只保留非图片附件，图片通过 `user_message.files` 回放为视觉输入。

保留本仓库 GitHub Release、Docker 多架构发布、独立 slim 构建和缓存等发布定制。生产前端继续保留 `console.error`，移除 `console.log`、`console.debug`。维护规则按用户要求拆为简洁的 AGENTS 索引和详细的 `docs/local-changes.md`。

## 合并后验证

- Python 3.11.16 与 3.12.14：各 48 项测试通过（MinerU 9、Responses 8、DeepSeek 23、sub-agent 8），测试依赖按项目版本隔离安装。
- 实际 OpenAI 路由至隔离提供商 HTTP 边界的 12 个场景全部通过，覆盖 Responses / Chat Completions、流式/非流式、原生 summary 与 effort 优先级。
- 执行实际 `index_file` 图片转换块和 `process_chat_payload` 检索消息接入块：小图片内部存储、图片字节保留、来源/已有附件去重、视觉关闭时不读取图片，以及所有者、管理员、显式授权、未授权与匿名权限均通过。
- 8 项 sub-agent 测试执行实际 delegate，覆盖请求附件、持久化当前图片、历史 MIME 图片、嵌套 ID、URL 选择、去重、缺失报告和未请求附件。当前请求图片继续通过实际消息图片回放块验证最终视觉输入。
- 前端 63 项单元测试通过（含 Markdown 35、模块恢复 18、语言初始化 6）。实际滚动函数与 HTML 早期语言脚本的上游/合并版对照通过。
- `npm ci --force`、`npm run i18n:parse` 通过，国际化解析未产生额外差异。`npm run build` 通过，静态站点生成成功；生产入口包含恢复标记及 `console.error`，没有 `console.log` / `console.debug` 调用。
- 合并版生产构建的浏览器故障注入：首次文档请求期间持续中断路由模块，自动重新请求文档一次后解除故障，页面恢复登录界面；代理记录 2 次文档请求、3 次模块失败，重试文档保留原查询及片段。持续模块失败时同样只有 2 次文档请求，随后停在 500 错误页且保留原查询及片段，没有循环刷新。
- 全仓 Prettier 检查、Python 编译和 `git diff --check` 通过。构建产生的 Pyodide 锁文件临时差异已还原。
- Ruff 格式检查覆盖 backend/tests 共 298 个 Python 文件；F 规则逻辑检查、离线 `uv lock --check --offline --python 3.12` 通过。
- 完整 Svelte 类型检查未通过。相同依赖下，原始 v0.12.5 有 5,631 个错误、188 个警告，合并版有 5,628 个错误、188 个警告。按类型、相对文件名及规范化诊断信息比较，没有新增诊断；既有 `autoScroll` boolean 声明消除 3 个上游诊断。构建成功不代表类型检查通过。

本次未调用真实 MinerU、DeepSeek 或模型服务。数据库、存储、提供商和子聊天的隔离边界测试不能替代真实外部服务集成验证。浏览器翻译弹窗受浏览器设置与实现影响，DOM 声明验证不能保证所有浏览器均不提示。未在测试或文档中记录真实 API 密钥。
